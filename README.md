# 雷霆曼巴格斗场

一款为手机横屏设计的静音单人格斗小游戏。玩家可选择“大帆帆”“小颜颜”“奶蛙”或“美团鼠”，对手由电脑 AI 随机控制。战斗采用侧视 3D 角色模型，每项攻击和防御都有对应动作姿态。

四名角色分别拥有雷霆、旋翼、熔金和暗月攻击特效，以及“雷霆曼巴升龙”“旋翼风暴”“熔金陨星”“暗月连舞”四种专属大招。

战斗系统现已加入连击计数、伤害递减、输入缓存、格挡耐久、破防和精准格挡慢动作。四名角色拥有独立被动：大帆帆三层雷印引爆、小颜颜特殊技加速强化、奶蛙周期性熔金霸体、美团鼠精准格挡触发幻影反击。

拳、直踢、扫堂腿、飞踢和空中下劈均使用与实际肢体位置对应的独立攻击框，腿技距离明确长于拳技。上勾拳、空中下劈、大招、破防及终结攻击可触发专属三段3D倒地动画，并包含躺地保护、爬起动作和短暂无敌时间。

命中角色时会触发受击后仰、红白闪烁、冲击环、伤害数字、屏幕震动与生命值残影；格挡则使用独立的减伤反馈。

移动端采用静态场景缓存、动作帧预合成和滤镜图层按需缓存，在完整保留粒子、辉光及大招效果的同时减少逐帧计算。

## 操作

- 左侧圆形虚拟摇杆：移动、跳跃和招式方向输入
- 拳：普通拳；上 + 拳为“超级上勾拳”；下 + 拳为“碎甲重拳”
- 腿：普通踢；下 + 腿为“雷霆扫堂腿”；上 + 腿为“螺旋大跳下劈腿”；前 + 腿为“流星飞踢”
- 挡：按住格挡
- 精准格挡：攻击命中前瞬间按挡；成功后触发慢动作与反击窗口
- 防御槽：连续承受格挡攻击会消耗防御槽，耗尽后进入破防硬直
- 必：能量槽充满后释放角色专属大招
- 桌面键盘：WASD / 方向键移动，J 拳，K 腿，L 格挡，U 大招

项目为纯静态 HTML/CSS/JavaScript，不包含背景音乐或音效。

## 本地运行

使用任意静态服务器打开项目目录，例如：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
